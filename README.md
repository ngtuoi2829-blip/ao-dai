# Áo Dài Việt – Nét đẹp vượt thời gian

Website phi lợi nhuận dùng để giới thiệu và trưng bày áo dài Việt Nam.

## Chạy website
1. Mở thư mục bằng VS Code.
2. Mở `index.html` bằng Live Server.
3. Không cần cài NodeJS hay cơ sở dữ liệu.

## Cấu trúc
- `index.html`: Trang chủ
- `lich-su.html`: 7 giai đoạn lịch sử áo dài
- `bo-suu-tap.html`: 5 nhóm áo dài + gallery ảnh
- `van-hoa.html`: Văn hóa áo dài
- `lien-he.html`: Liên hệ mô phỏng
- `style.css`: Giao diện
- `script.js`: menu mobile, gallery, form mô phỏng
- `img/`: logo, banner và 9 ảnh mẫu
